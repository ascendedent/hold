# Hold

A local training log. Build routines, log sets, track body measurements, and keep your own notes. It binds to this computer only.

```bash
npm install
npm run dev
```

Open http://127.0.0.1:4747

Your workouts, body log, and notes live in `data/hold.db`. That file stays on this machine.

The exercise catalog is the [Free Exercise DB](https://github.com/yuhonas/free-exercise-db) (public domain). Photos are loaded from that repository when you open an exercise. They are not stored here. A YouTube link, if you paste one on an exercise, streams inside the app.

Hold is a training log, not medical advice.
